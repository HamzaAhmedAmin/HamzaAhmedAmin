* Data Cleaning
* Exploratory Data Analysis
* Feature Engineering
* Time Series Forecasting
* LightGBM

### 🏨 Hotel Booking Performance Analysis

Business Intelligence project analyzing **119K+ hotel bookings**.

* SQL Server
* Data Modeling
* Star Schema
* DAX
* Power BI
* Data Visualization
* Business Insights
